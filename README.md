# Coach portraits

The ten 128px greeting portraits for Ivan's coaching roster, served through jsdelivr so a coach types a short URL instead of a 3,500-character data URI.

Displayed at 64px (2x for retina). Generated from the vault's `Coach Portraits/thumbs/` at q90.

**Always reference a pinned commit**, never a branch:

`https://cdn.jsdelivr.net/gh/iguedespinto/coach-portraits@<commit>/<Name>.jpg`
